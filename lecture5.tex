\section*{Lecture 5: Structure Sheaf of Spec $\!R$}
Recall that for a ring $R$ we have defined an 'incomplete' presheaf $\mathcal{F}$ on the base of the topology $\{D_f\}$, given by
\[
\mathcal{F}(D_f) = R_f
\]
We will show that this 'incomplete' presheaf satisfies the sheaf axioms. In what follows we have $U = \cup U_i$ where $U, U_i$ are open sets in the base of the topology.
\newline\newline
We need to show that 
\begin{enumerate}
\item If $f,g\in \mathcal{F}(U)$ such that $f=g$ in $\mathcal{F}(U_i), \forall i$, then $f=g$ in $ \mathcal{F}(U)$.
\item If $f_i\in  \mathcal{F}(U_i)$ such that $f_i = f_j$ in $ \mathcal{F}(U_i\cap U_j)$, then $\exists f\in  \mathcal{F}(U)$ with $f=f_i$ in $ \mathcal{F}(U_i)$.
\end{enumerate}
Note that $U_i\cap U_j$ is not always in the base of the topology, in which case the condition $2.$ is replaced with
\[
\text{\dots such that $f_i = f_j$ in $ \mathcal{F}(V)$ for every $V\subset U_i\cap U_j$, $V$ an open set in the base}
\]
However for this specific case we know that $D_f\cap D_g = D_{fg}$, so the base is closed under finite intersections. We leave the full verification of these axioms as an exercise, checking only the case $U = \text{spec }\!R$ with open cover $\text{spec }\!R = D_s\cup D_t$.
\begin{proof}[Proof of 1.]
We know that $\text{spec }\!R = D_s\cup D_t$ if and only if no prime ideal contains $s$ and $t$, so $\langle s,t\rangle = (1)$. By the assumption that $f=g$ in $R_s$ and $R_t$ we obtain
\[
s^n (f-g) = 0,\quad t^m(f-g) = 0
\]
for some $m,n\in\N$. Then by considering the $m+n$-th power of $\langle s,t\rangle$ we obtain $\langle s^m ,t^n \rangle = (1)$ as well. Take $A,B\in R$ such that $As^n + Bt^m = 1$, then
\[
0 = As^n (f-g) + Bt^m(f-g= (As^n + Bt^m )(f-g) = f-g
\]
so $f=g$ in $R$ as required.
\end{proof}
\begin{remark}
If we instead had $\text{spec }\!R = \cup_{i\in I} D_{s_i}$ for some potentially infinite set $I$, then the ideal generated by the $s_i$ would contain $1$, however this means a finite linear combination of the $s_i$ is equal to $1$, so we can take a finite subcover of the $D_{s_i}$ by only using the $s_i$ that appear in our expression for $1$. 
\newline\newline
Since every open cover has a refinement of the above form we obtain that every open cover of $\text{spec }\!R$ has a finite subcover. So $\text{spec }\!R $ is {\it quasicompact} as a topological space, the {\it quasi} is used to signify that the space is not necessarily Hausdorff, in fact $\text{spec }\!R$ is almost never Hausdorff. Quasicompact spaces do not have the same advantages as compact ones, for example the continuous image of a qauasicompact space need not be closed. The better analogue for compactness is {\it properness}, which we will define later.
\end{remark}
For proving axiom 2. we will use an argument analogous to the classical partition of unity to piece together local data to form a single global element.
\begin{proof}[Proof of 2.]
Let $f_1\in R_s$ and $f_2\in R_t$ be such that $f_1=f_2$ in $R_{st}$, we write
\[
f_1 = \frac{a}{s^{m}} = \frac{as^k}{s^{m+k}},\quad f_2 = \frac{b}{t^{n}} = \frac{bt^k}{t^{n+k}},
\]
where $k$ is chosen such that
\[
s^kt^k(t^na-s^mb) = 0.
\]
As before there exists $A,B\in R$ such that $As^{m+k} + Bt^{n+k} = 1$, so we let
\[
f = Aas^k + Bbt^k = \frac{Aas^k + Bbt^k }{As^{m+k} + Bt^{n+k}} \in R
\]
and claim that this is our desired $f$. To see that $f=f_1$ on $D_s$ observe
\begin{align*}
(Aas^k + Bbt^k)s^m - a(As^{m+k} + Bt^{n+k}) &= Aas^{m+k} + Bbt^ks^m - aAs^{m+k} - aBt^{n+k})\\
&= Bt^k(bs^m - at^{n}),
\end{align*}
with multiplying by $s^k$ yields $Bs^kt^k(bs^m - at^{n})=0$ as required. The argument on $D_t$ is much the same so we are done.
\end{proof}
We have shown that the axioms of a sheaf are satisfied on the base set, the following proposition will allow us to conclude that this defines a sheaf on the whole space as desired.
\begin{proposition}
A presheaf on a base that satisfies the sheaf axioms on the base extends uniquely to a sheaf.
\end{proposition}
In fact the same is true for morphisms , that is, given sheaves on a base $\mathcal{F}, \mathcal{G}$ and a collection of maps 
\[
f(U): \mathcal{F}(U) \to \mathcal{G}(U)
\]
for every $U$ in our base, then $f$ extends uniquely to a morphism of sheaves. The proposition could be stated as the following equivalence of categories 
\[
\left\{
\begin{array}{c}
\text{sheaves on}\\
\text{a base}
\end{array}
\right\}
\;\simeq\;
\left\{
\begin{array}{c}
\text{sheaves on the}\\
\text{whole space}
\end{array}
\right\}.
\]
\begin{example}
    Recall the presheaf in lecture 2 non-example 2.2, given by $U\mapsto \Z, \emptyset\mapsto \{0\}$. This defines a sheaf on the base of open balls, as each open ball is connected so we no longer face the previous obstruction to axiom 2. The sheaf this extends to is the sheaf of locally constant functions with values in $\Z$.
\end{example}
\begin{proof}
    Given a sheaf $\mathcal{F}$ on a base $U_i$, the first candidate for the value of $\mathcal{F}(U)$ is to take some open cover $U = \cup U_i$ and define
    \[
    \mathcal{F}(U) = \left\{ \left(f_i \in \mathcal(U_i)\right) \mid f_i = f_i\text{ on every basic }V\subset U_i \cap U_j \right\}.
    \]
However this definition depends on the choice of cover, so to remedy this we always take the biggest possible open cover. Thus we define
\[
\mathcal{F}(U) := \left\{ \left(f_i \in \mathcal{F}(U_i)\right)\,\forall U_i\subset U \mid U_j \subset U_i \implies f_j \in \mathcal{F}(U_j)\text{ is the image of }f_i\in\mathcal{F}(U_i) \right\}
\]
Some might recognise this as the inverse limit $\varprojlim_{\substack{U_i \subset U}} \mathcal{F}(U_i)$. We leave it as an exercise to verify the sheaf axioms.
\end{proof}
From now on we will use $(X,\mathcal{O}_X)$ to denote the structure sheaf on $X =\text{Spec }\!R $. The following examples will illustrate what the structure sheaf looks like in practice.
\begin{example}
    Let $R = \C[x,y]$, then we define $\A^2_\C:=\text{Spec }\!R$ and consider the open set $U = \A^2 - (0,0) = \!\text{ Spec }\!R - (x,y)$, note $U$ is the complement of the closed point corresponding to the maximal ideal $(x,y)$. We wish to characterise $\mathcal{O}_{\A^2}(U)$. Note that $U$ consists of those ideals which do not contain either $(x)$ or $(y)$, thus
    \[
    U = D_x \cup D_y
    \]
    We know that
    \[
    \mathcal{O}_{\A^2}(D_x) = \C[x,y]_x = \left\{ \frac{f(x,y)}{x^n} \mid f\in R, n\in\N\right\}
    \]
    and similarly
    \[
    \mathcal{O}_{\A^2}(D_y) = \left\{ \frac{g(x,y)}{y^m} \mid g\in R, m\in\N\right\}.
    \]
    Since $R$ is a domain we can regard all localisations as sitting inside the fraction field, in this case $\C(x,y)$. Hence
    \[
    \mathcal{O}_{\A^2}(U) = \left\{ \left(\frac{f(x,y)}{x^n}, \frac{g(x,y)}{y^m}\right) \text{ which agree on }\C[x,y]_{xy} \right\},
    \]
    however because we are working in the fraction field this condition is equivalent to
    \[
    y^mf(x,y) - x^ng(x,y) = 0
    \]
    so $f(x,y) = x^nF(x,y)$ and $g(x,y) = y^mG(x,y)$, and in fact $F=G$. Thus we may write
    \[
    \mathcal{O}_{\A^2}(U) = \left\{ (F, F) \right\}
    \]
    We then consider the map
    \[
    \mathcal{O}_{\A^2}(\A^2)\to \mathcal{O}_{\A^2}(U)  
    \]
    \[
    \C[x,y] \ni a \mapsto \{ (a,a) \}
    \]
    Which is an isomorphism of rings.
\end{example}
\begin{example}[Examples of structure sheaves]
We now give some more examples with familiar rings.
\begin{itemize}
    \item Let \(X = \operatorname{Spec}\C\). Since \(\C\) is a field,
    \[
        \operatorname{Spec}\C
        =
        \{(0)\}.
    \]
    Hence
    \[
        \mathcal{O}_X(X)
        =
        \C.
    \]
    \item Let
    \[
        X
        =
        \operatorname{Spec}\frac{\C[x]}{(x^2)}.
    \]
    The only prime ideal is \((x)\), since \(x\) is nilpotent. Thus
    \[
        X = \{(x)\},
    \]
    and
    \[
        \mathcal{O}_X(X)
        =
        \frac{\C[x]}{(x^2)}.
    \]
 \item Let \(X = \operatorname{Spec}\Q\). Then
    \[
        \operatorname{Spec}\Q
        =
        \{(0)\}.
    \]
    Hence
    \[
        \mathcal{O}_X(X)
        =
        \Q.
    \]
    \item Let
    \[
        X = \operatorname{Spec}(\mathbb{Z}/6\mathbb{Z}).
    \]
    The prime ideals are
    \[
        (2),\quad (3),
    \]
    so
    \[
        X = \{(2),(3)\}.
    \]
    We know
    \[
    \mathcal{O}_X(X) = \mathbb{Z}/6\mathbb{Z}
    \]
   Then
    \[
        D_2
        =
        \{(3)\},
    \]
    implies
    \[
        \mathcal{O}_X(D_2)
        =
        (\mathbb{Z}/6\mathbb{Z})_2
        \cong
        \mathbb{Z}/3\mathbb{Z}.
    \]
    Similarly,
    \[
        D_3 = \{(2)\} \implies \mathcal{O}_X(D_3) = (\mathbb{Z}/6\mathbb{Z})_3 \cong \mathbb{Z}/2\mathbb{Z}.
    \]
From which we recover $\Z/6\Z \cong \Z/2\Z\times \Z/3\Z$, as the Chinese remainder theorem states.
    \item Let
    \[
        X = \operatorname{Spec}\mathbb{C}[|t|].
    \]
    The prime ideals are
    \[
        (0),\quad(t),
    \]
    We know
    \[
     \mathcal{O}_X(X) = \C[|t|]
    \]
    and $D_0 = \emptyset\mapsto \{0\}$, thus we consider
    \[
    D_t = \{(0)\} \implies \mathcal{O}_X(D_t) = \C[|t|]_t = \C\left((t)\right)
    \]
\end{itemize}
\end{example}
More generally, let $X = \operatorname{Spec}R$ and let \(\mathfrak{p}\in X\). Then the stalk at $\mathfrak{p}$ given by
    \[
        \mathcal{O}_{X,\mathfrak{p}}
        =
        \varinjlim_{\mathfrak{p}\in U}
        \mathcal{O}_X(U).
    \]
    Using the basis of open sets \(D_f\), this becomes
    \[
        \mathcal{O}_{X,\mathfrak{p}}
        =
        \varinjlim_{\substack{f\notin\mathfrak{p}}}
        \mathcal{O}_X(D_f)
        =
        \varinjlim_{\substack{f\notin\mathfrak{p}}}
        R_f
        \cong
        R_{(\text{complement of $\mathfrak{p}$)}}
    \]
Where we are localising at every $f\notin \mathfrak{p}$, so the denominators come from the complement of $\mathfrak{p}$.
\begin{example}
    In Spec $\! \Z$ the stalk at $(5)$ is given by
    \[
    \left\{ \frac{a}{b} \mid 5\nmid b \right\}
    \] 
\end{example}
\begin{example}
    In Spec $\! \C[x,y]$ the stalk at $(x,y)$ is given by
    \[
    \left\{ \frac{f(x,y)}{g(x,y)} \mid g(0,0)\neq 0 \right\}
    \] 
\end{example}
